# VerifyW3

## Requisitos

- [Node.js](https://nodejs.org/) 18 o superior (incluye `npm`)
- Un navegador web moderno (Chrome, Edge, Firefox)

## Instalación

```bash
cd frontend
npm install
```

## Cómo correrlo

```bash
npm run dev
```

Abre la dirección que aparece en la terminal (por defecto http://localhost:5173).

Para generar la versión de producción: `npm run build`.
